## v6 (2026-10-22) 1.4 R 식 표현

- 1.4 오른쪽 위 식: 'R_ant = J · diag(σ²) · J^T, R_NED = M · R_ant · M^T' (야코비안 J, 회전 M 두 단계) 를
  'R_NED = C · diag( σr², (r cos el · σaz)², (r · σel)² ) · C^T' 한 줄로 바꿈
  - 가운데 (파랑) = 레이다 시선 기준 거리 · 옆 · 위아래 오차 크기 (각도 × 거리 = 미터)
  - 앞뒤 C (초록) = 시선 기준 축을 북 · 동 · 아래 축으로 돌리는 회전 행렬 (안테나 방향 + 플랫폼 자세)
  - 1.3 · 1.5 의 T (스캔 시간 차) 와 헷갈리지 않게 회전은 C 로 씀
- 코드 (f_Trk_MeasCov) 의 두 단계 계산과 같은 식: J 의 열을 길이 1 로 나누면 시선 · 옆 · 위아래 단위 벡터와 배율 1, r cos el, r 로 갈리고,
  C = M · (단위 벡터) 는 회전 행렬. 임의의 거리 · 각도 · 자세 2,000 경우에서 두 식의 차이 1e-15 이하 확인
- 1.4 대본 수정, 7 번 장만 바뀜 (다른 장은 v5 와 같음)
