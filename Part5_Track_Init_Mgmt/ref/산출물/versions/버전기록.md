1. 최신본을 고친 뒤 이 폴더에 `v5_날짜_내용` 폴더를 만들고 pptx 와 대본을 버전 번호를 붙여 복사

4. git 은 main 하나만 쓰고, 커밋 메시지에 버전을 적음 (예: `과제5 v5: ...`)
