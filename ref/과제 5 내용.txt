1.1 1-Point Track Initiation
    - 측정치(플롯) 한 개만으로 트랙을 생성하는 방법
    - 신속히 트랙을 개시할 수 있는 것이 장점
    - 초기 트랙의 속도 오차가 큰 단점
1.2 2-Point Track Initiation
    - 연속된 두 스캔 또는 드웰에서의 측정치(플롯)들을 이용하여 트랙의 초기 상태 변수와 오차공분산을 계산하는 방법
    - 2개 플롯의 시간에 따른 위치 변화량 계산이 가능하여 1-Point Track Init. 방법에 비해 속도 오차를 줄일 수 있는 것이 장점
    - 연속된 두 시점의 측정치 정보를 이용해야 하기 때문에 1-Point Track Init. 방법에 비해 개시 시간이 오래 걸림

* 속도 게이팅
표적이 가질 수 있는 최대 속도값V_max_을 게이팅 최대값으로 설정하여 연속 스캔(드웰)에서 탐지된 플롯 위치 정보를 이용해 계산한 위치변화량 크기가 V_max보다 작은 경우 트랙 개시를 수행한다.
|z_(k,i) - z_(k-1,j)| / deltaT < V_max

2.1 M/N 방식
(1) 임시 트랙
    - M번 연속 결합 실패 -> 트랙 삭제
    - N번 중 M번 트랙 연관 성공 -> 트랙 확정
(2) 확정 트랙
    - 트랙 연관 실패 -> 메모리 트랙 전환
    - 특정 시간 이상 메모리 상태 유지 -> 트랙 삭제

2.2 트랙 스코어 방식
(1) 임시 트랙
    - 트랙 스코어 <= 임시 트랙 삭제 스코어 -> 트랙 삭제
    - 트랙 스코어 >= 트랙 확정 스코어 -> 트랙 확정
(2) 확정 트랙   - 트랙 연관 실패 -> 메모리 트랙 전환, 메모리 스코어=+1
(3) 메모리 트랙
    - 트랙 연관 성공 -> 확정 트랙 전환, 메모리 스코어 = 0
    - 메모리 스코어 >= 메모리 트랙 삭제 스코어 -> 트랙 삭제

3. 트랙 개시 및 관리 기능 구현
    1. 트랙 개시(2 Point Track Init 적용)
        - 표적 상태 변수 : X_k = [x_k x'_k x''_k y_k y'_k y''_k z_k z'_k z''_k]^T
        - 2 Point 트랙 초기화 속도 게이팅 V_max = 800m/s로 설정
        - 2 Point 트랙 초기화 시 트랙 초기 상태변수(mat_EstX) 및 트랙 초기 오차 공분산(mat_EstP) 가속도 항은 0으로 설정
        - 트랙 생성 후 트랙 ID 부여 (100~10000)
    2. 트랙 관리(Track Score 기반 로직 적용)
        - 임시 트랙 확정 문턱치 : 5
        - 임시 트랙 삭제 문턱치 : 0
        - 메모리 트랙 삭제 문턱치 : 5
        - 확정 트랙에서 메모리 틀랙 전환 이후 트랙 연관이 되면 바로 확정 트랙으로 다시 전환(이때 메모리 스코어는 0으로 초기화)
        - TrackScore: 트랙 점수, MemoryScore: 메모리 점수, TrackState: 트랙 상태(1:임시트랙, 2:확정트랙, 3:메모리트랙, 4:삭제트랙)
    3. 시뮬레이션 방법 및 결과
        - 플롯 생성 후 데이터 처리를 수행하기 위해 플롯을 수신 받는 쓰레드에 안테나 구좌표계 성분으로 구성된 플롯 메시지(STRUCT_PlotMsg) 전송
        - 플롯 데이터에는 표적플롯과 클러터가 같이 포함되어 있으며 매스캔마다 생성된 플롯에 ID 부여(10000~1000000)
        - 플롯 데이터 전송 방식은 UDP 또는 TCP/IP 방식 적용
        - 현재 추적 필터 및 트랙 연관 기능이 구현되어 있지 않기 때문에 생성된 트랙은 매 스캔마다 트랙 연관 상태(Assigned_Flag)를 실패('0')로 부여(성공 '1')
        - 시뮬레이션 결과 화면에는 True, Plot, Track 심볼이 동시에 표현될 수 있도록(3D, 2D)
