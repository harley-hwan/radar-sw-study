1. 플롯 생성
- 플롯이란?
- 플롯 생성 과정
(1) 실제 레이다 시스템 시퀀스에 따른 플롯 추출 과정
  -> 표적(True Target) 정보 + 잡음(Noise)
  -> 표적신호 생성: IQ데이터
  -> 신호처리: 펄스압축 -> 도플러처리 -> Cfar -> Hit추출 -> Hit 크러스터링 -> 모노펄스 처리 -> 드웰 플롯
(2) 추적 알고리즘 또는 기능/성능 검증을 위한 플롯 모의 과정(표적신호 생성 및 신호처리 과정 생략)
  -> 표적(True Target) 정보 + 잡음(Noise) -> 드웰 플롯

2. 플롯 모의
2. 플롯 모의 방법
- 표적, SNR, 레이다 파라미터 정보를 이용하여 표적의 안테나 좌표계 기준으로 거리, 방위각, 고각에 대한 표준편차 성분 계산 후 가우시안 정규 분포를 이용하여 성분별 잡음 성분 추출을 통해 플롯 모의
(1) 레이다 시스템 파라미터 정보를 이용하여 표적 SNR 계산
   - Beam Azimuth, Beam Elevation, BandWidth.. -> Target SNR
(2) 시스템 파라미터 및 SNR 정보를 이용하여 표적의 거리, 방위각, 고각에 대한 표준편차 추출
  - p_rng = light speed / (2 * BandWidth * sqrt(2*SNR)), p_azi = BeamAzimuth / (KM_Azi * sqrt(2*SNR)), p_ele = BeamElevation / (KM_Ele * square(2*SNR))
(3) 가우시안 정규분포를 이용한 거리, 방위각, 고각 잡음(오차) 성분 추출
- v_rng ~ N(0, p_rng^2)
- v_azi ~ N(0, p_azi^2)
- v_ele ~ N(0, p_ele^2)
(4) 플롯 거리, 방위각, 고각 성분 계산
- z_rng = x_rng + v_rng
- z_azi = x_azi + v_azi
- z_ele = x_ele + v_ele

3. 클러터
- 클러터란?
- 클러터 생성
(1) 특정한 환경에서 발생할 수 있는 클러터 모의는 해당 환경의 다양한 변수를 고려하여 복잡한 모델링 과정이 필요한 하나의 연구분야이기 때문에 데이터 처리 기능 및 검증 과정을 위한 시뮬레이션 수준에서는 이를 반영하기 힘듦
(2) 해상환경과 같이 전 영역으로 클러터가 무작위 적으로 발생할 수 있는 환경을 간단한 방법으로 시뮬레이션에 모의함으로써 클러터 환경에서 표적을 강건하게 추적할 수 있는 추적기법을 검증할 수 있음

4. 클러터 모의 방법
(1) 클러터 생성 개수 입력(한 스캔동안 최대 몇 개의 클러터를 생성할지)
(2) 거리, 방위각, 고각 성분별로 클러터가 생성될 수 있는 FOV 범위 설정(min ~ max)
(3) Uniform 랜덤변수를 이용하여 F.O.V 내에 안테나좌표계(구좌표계) 상에서의 클러터의 거리, 방위각 그리고 고각 성분 추출

5. 플롯, 클러터 모의 결과
5. 표적 플롯, 클러터 모의 시뮬레이션 결과
 -5개 표적에 대한 True Target, 플롯, 클러터 모의 결과 전시 화면

6. C 코딩을 통한 해당 내용 검증
1. 학습 목표
플롯, 클러터를 간단히 모의하는 방법을 학습하고 구현을 통해 결과를 확인한다.

2. 실습 내용
2.1 랜덤변수 학습 및 관련 함수 사용을 통한 기능 확인
- 제공한 UNIRAN, GAUSS 함수 사용하거나 직접 제작 구현한 함수 사용 가능
- UNIRAN : 10,000개 난수 생성 후 폐구가(0~1)에서의 확률밀도분포가 '1'에 수렴함을 확인
- GAUSS: 평균 0, 표준편차 1에 대한 10,000개 난수 생성 후 확률밀도분포가 표준정규분포를 따르는지 확인

2.2 플롯 모의
(1) 이전 자수에서 구현한 대공 표적 및 플랫폼 위치 정보 이용
(2) SNR 20 고정
(3) 표적의 거리, 방위각, 고각 표준편차 추출(light speed:299792458.0m/s, BeamAzi:5.14[deg], BeamEle:5.31[deg], BandWidth:5MHz, KM_azi:1.7 KM_ele:1.7)
(4) 가우시안 랜덤변수를 이용하여 표적의 거리, 방위각, 고각 잡음 성분 추출하여 플롯 모의

2.3 클러터 모의
(1) 균등 랜덤변수를 이용하여 스캔당 5개의 클러터에 대한 거리, 방위각, 고각 모의
(2) 클러터 모의 범위
- 거리: 200m ~ 15,000m
- 방위각: -60도 ~ +60도
- 고각: 0도 ~ +30도

3. 기타 사항
(1) 전체 시뮬레이션 시간: 60초, 시간 갱신 간격(1스캔 시간): 0.1초
(2) True Target, 플롯, 클러터 위치 정보를 LLA 좌표계상에서 전시, 각각의 심볼 색상은 다르게 표현하여 구분될 수 있도록
